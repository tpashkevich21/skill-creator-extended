# Skill Creator Extended

Адаптированная версия исходного `skill-creator` для общего использования в **Codex и OpenCode** через формат Agent Skills.

## Куда устанавливать

Рекомендуемая общая пользовательская папка Windows:

```text
%USERPROFILE%\.agents\skills\skill-creator-extended\
```

Например:

```text
C:\Users\<имя-пользователя>\.agents\skills\skill-creator-extended\SKILL.md
```

Это пользовательский путь `$HOME/.agents/skills` для Codex и совместимый глобальный путь для OpenCode. Установка в `plugins` не требуется.

## Установка

1. Создайте папку `%USERPROFILE%\.agents\skills`, если её ещё нет.
2. Распакуйте ZIP **внутрь** `%USERPROFILE%\.agents\skills`.
3. Убедитесь, что получился путь `%USERPROFILE%\.agents\skills\skill-creator-extended\SKILL.md`.
4. Перезапустите Codex или обновите сессию OpenCode, если навык не появился в списке доступных навыков.

В архиве уже есть единственная верхнеуровневая папка `skill-creator-extended`. Не распаковывайте содержимое этой папки в `.agents\skills` без самой папки навыка.

## Что адаптировано

- Идентификатор изменён на `skill-creator-extended`, чтобы не конфликтовать со встроенным в Codex навыком `skill-creator`.
- Основная методика переписана в нейтральном виде для Codex и OpenCode: нет предположений о Claude CLI, конкретных именах инструментов или механизме запуска подагентов.
- Добавлен экономный режим: по умолчанию не запускаются бенчмарки, повторные тесты, автоматические циклы улучшения или массовые проверки.
- Файлы в `agents/` обозначены как шаблоны ролевых инструкций. Они сами по себе не регистрируют отдельных подагентов.
- Claude Code-специфичные скрипты `run_eval.py`, `improve_description.py` и `run_loop.py` сохранены отдельно в `legacy/claude_code_only/`. Они используют `claude -p` и `.claude/commands` и **не предназначены для запуска из Codex или OpenCode**.
- Сохранены исходные вспомогательные материалы, схемы, HTML-просмотрщик и лицензия Apache 2.0.

## Состав

- `SKILL.md` — основная инструкция.
- `agents/` — шаблоны для оценщика, слепого сравнения и аналитика.
- `references/schemas.md` — необязательные схемы JSON для тестов и результатов.
- `scripts/quick_validate.py` — структурная проверка папки навыка.
- `scripts/package_skill.py` — создание ZIP-архива формата `.skill`.
- `scripts/aggregate_benchmark.py` — агрегация уже полученных результатов, без запуска моделей.
- `eval-viewer/` — HTML-просмотрщик подготовленных результатов.
- `assets/` — HTML-шаблон для ручной проверки запросов активации.
- `legacy/claude_code_only/` — сохранённые Claude Code-специфичные скрипты.

## Проверка

Основная инструкция и структура рассчитаны на общий формат Agent Skills. Скрипт-валидатор требует Python 3.10+ и PyYAML:

```powershell
python -m pip install pyyaml
python .agents/skills/skill-creator-extended/scripts/quick_validate.py .agents/skills/skill-creator-extended
```

Валидатор проверяет frontmatter и совпадение имени папки с полем `name`. Это не заменяет проверку реального обнаружения и работы навыка в каждом хосте.

## Ограничения совместимости

Навык подготовлен для общего формата и общих путей Codex/OpenCode, но фактическое выполнение в обоих приложениях отдельно в этом пакете не тестировалось. Некоторые функции хостов, например делегирование подагентам, локальный сервер и автоматическое измерение активации навыка, зависят от конкретного приложения и должны проверяться в нём отдельно.
